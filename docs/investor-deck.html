Решение

Связь через ощущения,
а не через текст

Pulse передаёт сигналы — касания, вибрацию, звук, свет — между двумя доверенными устройствами. Никакого текста, никаких лент, никакой аналитики.

Как это работает

Три шага до связи

1

Сопряжение

Один создаёт 6-значный код, второй вводит его. Обмен публичными ключами Curve25519 через сигнальный сервер.

6-digit code
2

Шифрование

ECDH → HKDF-SHA-256 → AES-256-GCM. Оба подтверждают 6-значный SAS-код. Ключи хранятся только на устройствах.

AES-256-GCM
3

Связь

Автоматический выбор канала: BLE → локальная сеть → интернет-реле. Без разрывов, с экспоненциальным backoff.

3 transport channels
