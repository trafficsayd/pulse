## Хостинг юридических страниц

Готовые файлы: `docs/legal/privacy.html`, `docs/legal/terms.html`
(двуязычные, самодостаточные).

**Вариант 0 — уже опубликовано (работает прямо сейчас):**

- Privacy Policy: https://hyperagent.com/s/CA6vXgwUABvLwCb9yT3o7g
- Terms of Use: https://hyperagent.com/s/naC5GsxsS4AU-Rz4U4Rwgg

Страницы захощены через платформу Hyperagent (публичны, без логина,
проверено). Годятся для полей Privacy Policy URL в обеих консолях и для
`--dart-define` в сборках. Когда появится собственный домен — просто
замените URL в консолях и в командах сборки; сами страницы в
`docs/legal/` остаются источником истины.

Другие варианты (собственный хостинг), любой займёт <15 минут:

1. **GitHub Pages этого репо** — Settings → Pages → Deploy from branch →
   дефолтная ветка / `docs/`. URL получатся
   `https://trafficsayd.github.io/pulse/legal/privacy.html` (это дефолт
   `LEGAL_PRIVACY_URL` в коде). ⚠️ На бесплатном тарифе GitHub Pages не
   работает из приватного репо — либо апгрейд, либо вариант 2.
2. **Отдельный публичный репо `pulse-legal`** с теми же двумя файлами +
   Pages. Тогда передавайте URL через
   `--dart-define=LEGAL_PRIVACY_URL=... LEGAL_TERMS_URL=...`.
3. Любой статик-хост (Cloudflare Pages — бесплатно и сочетается с
   Worker'ом).

В Terms по умолчанию для iOS-сборок используется стандартная EULA Apple
(`apple.com/legal/internet-services/itunes/dev/stdeula`) — этого Apple
достаточно; собственные Terms нужны, если хотите единый документ на обеих
платформах (файлы уже готовы).

⚠️ Не забудьте: e-mail в юридических документах и `settingsSupportEmail`
в `lib/l10n/app_*.arb` должны стать реальным адресом поддержки.
